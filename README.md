# FFXI Addons — by Jboor

Ashita v4 addons for Final Fantasy XI, made for the **Phoenix** private server (level 75 cap). Theeb theme.

| Addon | Job | What it does |
|---|---|---|
| [6arab](6arab/) | BRD | Floating song tracker — draining note tiles, melee / mages rows, debuff bars, ability cooldowns |
| [nard](nard/) | COR | Floating roll tracker — dice with lucky / unlucky / bust effects, Double-Up window, roll cooldowns |

## Install

1. Download this repo (green **Code** button → **Download ZIP**) or grab a zip from **Releases**.
2. Copy the addon folder (for example `6arab`) into `Ashita/addons/`.
3. In game: `/addon load 6arab`

Every addon has a settings window (`/<addon>`) and a debug log (`/<addon> log`).
