# FFXI Addons — by Jboor

Ashita v4 addons for Final Fantasy XI, made for the **Phoenix** private server (level 75 cap).

| Addon | Job | What it does |
|---|---|---|
| [6arab](6arab/) (طرب, *the joy of music*) | BRD | Floating song tracker — draining note tiles, melee / mages rows, debuff bars, ability cooldowns |
| [nard](nard/) (نرد, *dice*) | COR | Floating roll tracker — dice with lucky / unlucky / bust effects, Double-Up window, roll cooldowns |

Addon names are Arabic words written in Arabizi (numbers stand in for Arabic letters, e.g. **6** = ط, **7** = ح, **9** = ص).

## Install

1. Download this repo (green **Code** button → **Download ZIP**) or grab a zip from **Releases**.
2. Copy the addon folder (for example `6arab`) into `Ashita/addons/`.
3. In game: `/addon load 6arab`

Every addon has a settings window (`/<addon>`) and a debug log (`/<addon> log`).
